# 趋势共振交易系统（v1.0）

## 一、核心逻辑

> 个股在 MA60 附近放量大阳线/涨停突破 → 板块有热点共振（涨停热度+百日新高厚度）→ 分歧缩量回踩 MA60 介入 → 趋势不破不走

不是追涨，是**等确认**。不是打板，是**做趋势启动段**。

---

## 二、选股流程（三步漏斗）

### 第一步：海选池 — 只看热点共振标的

每天开盘前/收盘后打开 **底部放量卡片**，只看顶部的 **🔥 热点共振** 栏。

条件（系统自动筛）：
- 涨幅 ≥7% 或涨停
- 收盘价在 MA60 的 -3%～+5% 范围内
- 所属板块同时在涨停热点 + 百日新高集中板块中
- 放量 ≥1.5倍60日均量

这一筛通常每天 **0～5 只**。没有就空仓。

### 第二步：精选 — 人工复核共振强度

对海选池的票，确认三点：

| 检查项 | 来源 | 过关条件 |
|--------|------|---------|
| 板块共振 | 交叉校验卡片 | 重合度 ≥40%（现在80% pass） |
| 板块厚度 | 百日新高板块分布 | 该板块有 ≥5 只新高 |
| 涨停集中度 | 涨停产业链 | 该板块有 ≥3 只涨停 |

如果交叉校验判定**非共振**（纯短线脉冲），海选池直接作废，当日不交易。

### 第三步：执行 — 分歧介入

**不做涨停次日追高**。等：

- **缩量回踩 MA60** 不破（最佳）
- 或**分时回踩均线不破**（次佳）
- 或**回调 2～3 天缩量**不再创新低（可接受）

---

## 三、仓位管理

| 共振强度 | 单票仓位 | 说明 |
|---------|---------|------|
| 强共振（重合度≥60%）| 20% | 板块共振厚，可正常仓位 |
| 中共振（40～60%）| 10% | 谨慎参与 |
| 无共振 | 0% | 空仓 |

每支票**止损 = MA60 下方 3%**。触发无理由砍。

---

## 四、持有与退出

**持有逻辑**：只要收盘价在 MA60 上方，持股不动。

**卖出信号**：
1. **收盘破 MA60** → 清仓（核心信号）
2. **连续 3 日缩量横盘不创新高** → 减半
3. **板块共振消失**（交叉校验从强共振掉到无共振）→ 减半
4. **放量滞涨**（放量 3 倍以上但涨幅＜3%）→ 减半

**不做**：不涨停就卖、不冲高就卖、补涨兑现就跑、看分时波动卖。

---

## 五、空仓纪律

> 交易频率由系统决定，不是由你决定。

| 情形 | 动作 |
|------|------|
| 热点共振栏 0 只 | 空仓 |
| 交叉校验判定纯短线脉冲（重合度＜20%）| 空仓 |
| 没有票回踩 MA60（都在天上）| 空仓 |
| 指数环境走坏（市场温度下降）| 减仓或空仓 |

## 六、与看板的对应关系

| 看板组件 | 你的用法 |
|---------|---------|
| 🔥 热点共振栏（新增）| 每天唯一关注的海选池 |
| 交叉校验卡片 | 判断今日是否可交易（共振/脉冲） |
| 底部放量列表（下方）| 备选池，人工手动翻 |
| 百日新高卡片 | 验证板块厚度，决定仓位 |
| 涨停产业链卡片 | 验证短期资金方向 |
| 补涨监测卡片 | 暂不纳入主系统（逻辑冲突） |

---

## 七、一句话原则

> **等共振确认 → 等 MA60 回踩 → 不破不走。没有共振就不做。**
