# 交易模式 4.0

## 数据源
- 悟道 MCP (wudao): 全市场行情/K线/资金流/涨停/题材/选股
- 迪雅数据 API: 备用行情数据 (基础版 ¥39/月)

## 核心工具链

### 1. 百日新高筛选与分类系统
五步筛选流程：
- 第一步: stock_screener 海选 (市值20-500亿/非ST/涨幅≥5%/量比≥1.5/近20日涨<30%/站上MA60)
- 第二步: 三通道分类 (游资点火型/机构建仓型/老庄对倒型)
- 第三步: 产业链五维验证 (概念/环节/龙头/利润/股东)
- 第四步: 买点信号监控 (买点A回踩/买点B分歧转一致)
- 第五步: 每日输出汇总

### 2. 板块生命周期分析
- 锚点日自动检测 (游资型≥15家/趋势型温和放大)
- 窗口不足标注"待确认"，状态持久化累积
- 三阶段标记: 初期(优先参与) / 中期(选择性) / 末期(仅龙头回流)
- 核心板块: 芯片/医药/机器人/算力/通信/商业航天/AI应用/物理AI

### 3. 每日简报
- 核心概念战场 (含生命周期列)
- 百日新高海选池
- 精选狙击池 + 买点监控
- 情绪观察池 + 分歧监控

## 运行方式
- 每日复盘: "交易模式4.0" → 自动执行筛选+生命周期+简报
- 单股研究: stock_research_workflow
- 题材挖掘: theme_intraday_capital + theme_stocks
- 条件选股: stock_screener (问财式自然语言)

## 回测策略参考
放量站上60日线: 信号日次日开盘买入 / 跌破5日线次日卖出 / 大盘需站上MA60
