# 百日新高股票筛选与分类系统

## 第一步：基础筛选
- 流通市值: 20亿 ~ 500亿
- 非ST股
- 当日涨幅 ≥ 5%
- 当日量比 ≥ 1.5
- 近20日涨幅 < 30%
- 收盘价站上MA60，MA60方向走平或向上
- 收盘价距MA60: 0% ~ 20%

## 第二步：三通道分类
- 通道一(游资点火型): 涨停 + 换手<5%
- 通道二(机构建仓型): 涨幅5-10% + 换手8-15%
- 通道三(老庄对倒型): 振幅>12% + 涨幅<5%

## 第三步：产业链五维验证 (通道二专用)
①核心概念板块 ②产业链环节 ③龙头/核心供应商 ④净利润同比增长 ⑤机构/北向持股
得分≥4/5 → 精选狙击池

## 第四步：买点信号
- 买点A(标准回踩): 缩量回踩MA5/10/20 + 止跌K线
- 买点B(分歧转一致): 分歧日次日缩量收阳/十字星

## API调用方式
- stock_screener: 主力选股，一次传入所有条件
- valuation_snapshot: 批量估值 (≤20只)
- kline: 批量K线 (≤20只, detailLevel=summary节省预算)
- financial_summary: 单股财务
- shareholder_structure: 单股股东
