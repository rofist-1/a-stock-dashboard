## 〇、核心思想（先读这段）

市场只有两种有效状态：**主升**（单一主线持续走强，能做波段）和**轮动**（题材快速切换，只能快进快出）。

- 每天盘后先跑 **判读器**，判定今天是哪种状态。
- 判定结果决定今天用哪套打法，**绝不混用**。
- 切换必须靠数据触发，**不靠感觉**。

一句话：**轮动做低吸赚溢价，主升做中军吃波段。判读器决定今天赚哪种钱。**

### 与旧体系的分工（不是二选一，是分析层→执行层）

| 场景 | 用什么 | 频率 |
|------|--------|------|
| 盘后判定模式 + 输出次日作战计划 | **新手册**（判读器 + 四层输出） | 每天必跑（约5分钟） |
| 盘后深度理解市场（结构/异常/数据是否健康） | 旧体系（13段式分析） | 有时间就跑，没时间跳过 |
| 盘中执行买点/卖点/止损 | **新手册**（三层次 / 轮动铁律 / 情绪开关） | 每天必执行 |
| 持仓体检（每只票留还是走） | 旧体系（持仓体检表） | 每周2-3次，或持仓变动时 |

- **冲突裁决：打法按判读器，仓位按 min(三锚上限, 模式上限)**。判读器只回答"怎么买"（主升三层次/轮动铁律），三锚/V3.5回答"买多少"（硬上限）——冲突时以 min 公式为准，判读器结论不推翻仓位红线。
- 例外：旧体系发现"数据异常/漏数据"等硬伤时，回查后修正判读器输入，而非直接推翻。
- 建议节奏：今晚首次实盘，先跑一遍旧体系13段式作为对照；若与判读器结论一致，后续即以判读器为主。

## 一、判读器：盘后5分钟五源打分

每日收盘后，采集五个信号，判断市场处于主升还是轮动。

### 五源打分表

| 判读源 | 主升模式信号 | 轮动模式信号 |
|--------|-------------|-------------|
| ① s1题材连续登顶天数 | ≥5天 | ≤2天就换帅 |
| ② 单题材百日新高占比 | **双口径并列**（满足任一即过）：一级行业占比≥25%，或最大细分占比≥20%（阈值已由全年回测标定） | 双口径皆不过且分散 <15%，谁都不突出 |
| ③ 大市值龙头量产新高 | 有（≥300亿龙头创百日新高） | 无，全是小票 |
| ④ 高度板 | 打开 >3板，**且高度板是主线方向贡献的** | 卡死 ≤3板；或高度>3板但全部非主线 |
| ⑤ **涨停端同步性闸门** | **涨停端第一主类 与 新高池 s1 同步**（同义词归一，见下） | 涨停端前3 都不含 s1 → 假主升，直接否决 |

### ⑤ 涨停端同步性闸门（v1.5 新增，全年回测已验证）

**判据**：用 `limit_up_filter`（date 参数）取当日涨停股的主类聚合（"匹配 N 条，主类 医药13、绿色电力4、通信4"），看第一主类是否与新高池 s1 同一主线。

- **严格同步**：涨停端第一主类 == s1（同义算）→ 主升成立
- **宽松同步**：涨停端前3 含 s1（允许涨停端滞后新高池 1 天）→ 主升成立
- **无同步**：涨停端前3 都不含 s1 → **假主升，同步否决**，判轮动

### ⑥ 涨停端拥挤度预警 + 高低切预警（v1.6 新增，主升末期识别）

在同步闸门（增量资金打哪里）之外，再监控两个**主升生命周期阶段**信号：

**A. 涨停端拥挤度预警（主升中后段）**
- 判据：涨停端第一主类家数 ≥5 天且 占比>50%（当日涨停总数中），= 主升居中段。
- **顶部预警**：拥挤度见顶后**首次回落**（如 8/13 医药涨停端占比 46/59≈78% → 8/14 回落到 9/63≈14% 之前，8/11-8/14 医药每日占涨停 40%+）→ 该主升已进末期，**2天内准备减中军**。

**B. 高低切预警（退潮确认）**
- 判据：防御板块（银行/农业/煤炭/石油石化/食品饮料/基建/地产链）**登上涨停端前3**。
  - 次席异动（前3出现防御）= **预警**：主线资金开始流出（8/18 农业23 登涨停端第3）
  - **榜首易主**（防御登第一）= **确认退潮**：8/19 地产链6/农业5/煤炭5 登前3，医药崩塌
- 看板已加「涨停榜首对比」列（🔁延续=同主线，🔄换帅·进防御=退潮确认），每日盘后扫一眼即可。

**实盘验证（8/13-8/19）**：
| 日期 | 涨停端 | 拥挤度 | 防御迹象 | 信号 |
|------|--------|--------|---------|------|
| 8/13 | 医药46/涨停59 | 78%（顶部挤压） | 无 | 主升末期预警 |
| 8/14 | 医药44但涨停端仅9 | 拥挤度见顶回落 | 无 | **顶部确认** |
| 8/17 | 医药38 | 平台 | 无 | 高位诱多 |
| 8/18 | 医药25 缩水 | 下降 | **农业23 登涨停端第3** | **高低切预警** ⚠️ |
| 8/19 | 医药12 | 崩 | **地产链6/农业5/煤炭5 登前3** | **退潮确认**，同步闸门否决 |

> 结论：**拥挤度见顶回落 + 防御板块登上涨停端 = 主升结束的组合信号**。8/18看到农业异动就该减医药仓，不必等到8/19跌停118。与⑤同步闸门、主升→轮动切换（涨停端衰减）互相印证，三套信号共用 limit_up_filter 数据源，不需要新增采集。

### 判定规则

- **五源全过 → 主升模式**
- **任一不过 → 轮动模式**（⑤无同步 = 直接轮动）
- **第④源瑕疵处理**：①②③④已过且⑤同步通过判主升，但高度板最高板不在主线上 → **不否决主升**，但候选池必须标注**"高度风险提示"**：主线高度不足，弹性层降为观望、中军低吸正常执行。
- **【实战记录 8/13】**：全场最高5板=秦安（机器人），医药最高仅誉衡4板 → ④瑕疵条款被真实触发，弹性层降观望；医药主线照常成立，条款处理有效。

## 二、主升模式执行（三层次买入）

主升 = 有确定性，可重仓、可拿波段。

### 三层次结构

| 层次 | 定义 | 买入方式 | 仓位 |
|------|------|---------|------|
| **中军层** | 主线内市值Top龙头，有机构新高确认 | **分批建仓**：主升初期(1-3日)按20日线/前低先建底仓1.5成，回踩5日线/分歧日再加1.5成，拿3-5周波段 | 3成 |
| **分支层** | 主线内未加速细分，有切换信号 | 竞价不弱+回踩均价，半程仓 | 2成 |
| **弹性层** | 高度龙/新高度候选 | 打板纪律，纯交易仓 | 1成 |

### 中军层选股标准

- 主线内市值 Top 或**辨识度第一梯队**（**非硬性≥300亿**；例：8/13康龙总市值仅91亿仍是主线中军，因当日创新高+龙头地位）
- 市值口径：**总市值 totalMv**（药明484亿/康龙91亿），区分流通市值 circMv（药明401亿/康龙70亿）
- 当日创百日新高（机构资金确认）
- 行业龙头地位明确

### 中军建仓节奏（防"5日线追不上"）

- **主升初期（判定通过1-3天）**：中军往往已沿5日线上行，回踩5日线机会少 → 按 **20日线/前低分批建底仓**（总仓一半）
- **主升中段**：沿5日线运行，回踩5日线/分歧日加另一半
- **禁忌**：不追单日加速（+10%以上大阳当天不追），等回踩或横盘企稳再买

### 分支层启动前置信号（出现2个才配仓）

1. 子分支出现首板涨停
2. 分支龙头进百日新高
3. 分支股竞价量比靠前

### 主升模式三铁律

1. **不追加速票**：主升加速段（单日20cm激增、涨停家数创阶段新高）不追当天涨停，只做回踩低吸
2. **中军能吃大段**：康龙化成/药明康德这类机构龙头，回踩就是上车，不是下车
3. **只做主线内**：主线外的一切（退潮板块、非主线高位股）一律不碰

### 历史案例（2026-08-13 医药主升）

- 中军：药明康德（总市值484亿/流通401亿，CXO龙头创新高）、康龙化成（总市值91亿/流通70亿，创新高）
- 分支：医药商业（柳药+6.14%新高、老百姓竞价量比5.59）
- 弹性：誉衡药业（4板，化学制药权重领涨，新高度候选）

## 三、轮动模式执行（四条铁律）

轮动 = 无确定性，只能轻仓快打。**这时你的仓位纪律比选股更重要。**

### 四条铁律

1. **放弃认证主线**：总仓压到 2-3成，单题材 ≤1成。宁可错过，不做错。
2. **当日跟强、次日只卖不买**：竞价跟当日最强（首板/低位）；买入后次日**按铁律四情绪开关决定去留**——开关未触发可持有1-2天，不强制每日换仓；次日若情绪开关触发新主线确认，可换仓到新最强；**次日绝不追昨日龙头**（往往是出货日）。
3. **只做首板/低位，不做连板**：轮动市连板高度顶在3板，是绞肉机。高度板≥4家+连板高度≥5板 才存在连板生态。
4. **情绪开关当闸门**：
   - 昨日涨停今表现 <0 → 收手
   - 断板率 >60% → 空仓
   - 封板率 <70% → 不做

### 轮动模式选股标准（次日低吸）

- 主板 + 站上MA20
- 当日主线题材内（不是最强那几只）
- 流通市值 20-500亿
- 近20日涨幅 ≤40%（未过热）
- 竞价量比靠前或量比放大

### 轮动模式禁止池（永远不碰）

- 当日涨停第一的题材（次日不接力）
- 高度板龙头（爱丽家居10板、传智8板这类）
- 昨日最强、次日高开冲高的票

### 历史案例（2026-08-05/06 通信轮动）

- 判定：轮动（普涨牛非主升，宽度强但涨停主类分散）
- 选中：中贝通信（光通信，竞价量比5.01，连续2天放量走强）
- 避开：传智8板、当日最强通信20/芯片18 不接力
- 验证：中贝连续走强3天，追高标被闷杀

## 四、模式切换触发条件（靠数据切，不靠感觉）

### 主升 → 轮动（涨停端衰减，v1.5 全年验证）

**判据**：用 `limit_up_filter` 对比主升日与次日的**涨停端该主类家数**，满足任一即切：

1. **衰减 ≥30%**：主升日 s1 在涨停端有 N 家，次日降到 ≤0.7N 家
2. **掉下第一**：s1 从涨停端第一主类位置被挤出（即便家数未衰减）

> **为什么看涨停端不看新高池**：8/13→8/14 医药新高池 46→44（-4%，无感），但涨停端医药 13→9（-31%）→ 切换。新高池是"存量筹码"慢变量，涨停端是"增量资金"快变量，**切换信号在涨停端**。全年验证：5/20→5/21 芯片 26→5（-81%）切、8/13→8/14 医药 13→9（-31%）切、5/19→5/20 芯片 11→26（+136%）延续 —— 3 样本全对。

> 注：原"主线涨停数锐减到个位数 + 龙头破5日线"的共振破位条款仍有效，作为涨停端衰减的补充确认（尤其涨停端数据缺失时）。

### 轮动 → 主升

- 判读器五源全过（以当日打分为准）
- 连续2个交易日满足新状态才正式切换（防假信号）

### 切换记录模板

```
日期 | 原模式 | 新模式 | 触发信号 | 是否连续2日确认
```

```

═══════════════════════════════════════════

【第二层：模式判定】

═══════════════════════════════════════════
```

## 六、仓位总纲

| 维度 | 轮动模式 | 主升模式 |
|------|---------|---------|
| 总仓上限 | 2-3成 | 6-7成 |
| 单题材 | ≤1成 | 主线内可集中 |
| 持仓周期 | 隔日~3日 | 3-5周 |
| 核心动作 | 竞价跟强/首板低吸 | 中军回踩低吸/拿波段 |
| 失败代价 | 小亏快走 | 需守纪律防回撤 |

### 与三锚表决的关系（冲突时取交集）

- **三锚表决**（趋势锚/广度锚/情绪锚）→ 定**硬性仓位上限**（买不买、买多少）
- **判读器** → 定**打法**（主升三层次 or 轮动铁律）+ 模式内软上限
- **冲突处理：最终仓位 = min(三锚上限, 模式上限)**。三锚判"震荡市≤50%"、判读器判"主升可70%" → 按 **50%** 执行；三锚判"上涨市70%"、判读器判"轮动≤30%" → 按 **30%** 执行。硬上限永远优先。

## 七、执行纪律（所有模式下通用）

1. **止损释放，当日冻结**：止损/止盈释放的资金当日不得重新买入，须等下一交易日。
2. **被动降仓按风险倒序**：先卖弹性/情绪仓，再卖趋势仓，最后才动中军。
3. **主线外高位股反弹必减**：非主线高位股（如泛微这类），反弹到压力位果断减仓，不恋战。
4. **任何票买入前确认三件事**：①属于当前模式允许的方向 ②买点条件（回踩/竞价）已触发 ③止损位已定。

## 十、情绪极值量化规律（v1.7 新增，全年155样本验证）

> 三条由全年数据（2026-01-05 ~ 08-20，155 个交易日）回验的可操作规律，用于**盘后快速定次日预期 + 仓位辅助**。与判读器（答"怎么买"）、三锚/仓位总纲（答"买多少"）并列，冲突时仍以 min 公式为准。

### 规律一：涨停绝对值分档（定次日进攻预期）

按当日涨停家数查档，直接给出次日方向期望：

| 当日涨停 | 次日平均 | 次日回升率 | 含义 | 操作 |
|---------|---------|-----------|------|------|
| **≥120** | -30.7 | 20% | 极度过热，拥挤兑现 | 次日不追高，见冲高减仓 |
| **80-119** | -17.5 | 24% | 过热 | 同上，仓位收一档 |
| **50-79** | +6.7 | 54% | 温和活跃 | 正常做，可低吸 |
| **<50** | +36.4 | **88%** | 冰点区 | **次日做多胜率最高**，但只做超短反抽 |

> 数据要点：121 个"涨停<50"的冰点日次日涨停均值 88 只是"反抽弹性"，不是趋势反转——超短当日兑现，不恋战。

### 规律二：跌停 8 警戒线（定未来3日风险窗口）

> 用户原始观察为"跌停>6 短期风险"，全年回验确认**方向正确但最优分界是 8 而非 6**：判别力（之上 73% vs 之下 35% 风险，+38pp）在 8 处最强。

| 当日跌停 | 未来3日风险概率 | 含义 | 操作 |
|---------|---------------|------|------|
| **≤8** | 36% | 正常环境 | 正常做 |
| **9-20** | 63-73% | 风险窗口开启 | **3日内见反弹先减仓**，当天不追 |
| **21-50** | 74-82% | 冰点区 | 歇一天等反抽，次日反弹做超短 |
| **>50** | 81% | 深冰点 | 次日几乎必反抽（均值+36），只做超短 |

> 关键认知（反直觉）：**跌停越多，次日涨停反而反弹更猛**（21-50 次日 +20.7，>50 次日 +36.1）。"跌停>8"警告的不是"明天就跌"，而是"**未来3天内大概率有一次风险释放（跌停>15 或涨停<40）**"——所以动作是**见反弹先降仓，而不是当天就空仓**。
> 与规律一同源：冰点窗口=涨停<50 或 跌停≥100 的同一宏观状态的两面。

### 规律三：涨跌家数 4000 冰点/沸点（定反转/分化预期）

> 2026-08-20 起看板补齐涨跌家数（此前全年无数，只能抽查极值日验证）。

| 极端日 | 规律 | 验证样本 | 操作 |
|--------|------|---------|------|
| **下跌>4000**（冰点） | **3日内反转**，但次日强反转仅50%，可连冰 | 8 样本：3日窗口 7/8 反转（88%） | 冰点当日不接飞刀，等**次晨确认**（竞价红盘）再轻仓反抽 |
| **上涨>4000**（沸点） | **次日分化 2/3**；若次日继续>4000（连沸）= 加速末段，第3日必崩 | 3 样本（7/27分化✓、3/24-3/25连沸后3/26崩、8/20待验） | 沸点次日不追涨；**连沸第2天最危险**，坚决空仓等第3日 |

> 反例记档：3/20 下跌4531 → 3/23 再跌4886（连冰），证明冰点可连续，必须等"次晨竞价确认"而非次日无脑抄底；7月主跌段同理。
> **8/20 实盘命中**：8/19 下跌5069（冰点）→ 8/20 上涨4096（教科书强反转），跌停 118→12。

### 三条规律的组合用法（盘后 30 秒）

1. 涨停查规一 → 定"明天进攻不进攻"
2. 跌停查规二 → 定"未来3天减不减仓"（比单一指标更早）
3. 涨跌家数查规三 → 定"冰点/沸点反转或分化"（极值日才触发）

三者互相印证时信号最强：**8/19（涨停36<50 + 跌停118>50 + 下跌5069>4000）三线全指冰点 → 8/20 当日强反转**，是全年教科书级共振。

## 十一、每日执行清单（Checklist）

**盘后（约10分钟）**
- [ ] 【前置】确认看板JSON已更新到当日（未更新→走stock_screener备选管道并标注口径差）
- [ ] 【首次终验】看板JSON取康龙化成，题材字段显示"创新药"=细分口径实锤；显示"医药"=另查剔除/口径原因
- [ ] 拉数据（市场宽度/涨跌停/梯队/题材资金）
- [ ] **拉涨停端主类**（limit_up_filter，读"主类 医药13、绿色电力4"行）——⑤闸门 + 切换判据 + ⑥拥挤度/高低切的地基
- [ ] **扫涨停榜首对比**（看板新列：🔁延续 / 🔄换帅·进防御）——⑥高低切预警
- [ ] **套用情绪极值三规律**（涨停分档→明日进攻与否；跌停分档→3日减仓与否；涨跌家数→冰点/沸点反转或分化）——十、章
- [ ] 跑五源打分（含 ⑤涨停端同步性闸门），判定主升 or 轮动；叠加⑥拥挤度/高低切检查主升生命周期阶段
- [ ] （可选）旧体系13段式对照核验判读器结论，发现数据硬伤则回查修正
- [ ] 主升：确定中军/分支/弹性候选 + 买点
- [ ] 轮动：确定次日低吸候选 + 禁止池
- [ ] 检查是否触发模式切换（主升日次日：涨停端 s1 衰减≥30% 或 掉下第一；或共振破位）
- [ ] 输出四层日报

**次日竞价（9:25）**
- [ ] 看高度龙颜色（高走=情绪延续，低开杀跌=歇脚/切换日）
- [ ] **冰点次晨确认**（规律三：跌停/下跌家数极端时，竞价红盘才反抽，竞价绿盘继续等）
- [ ] 候选池竞价强度排序，确认买点是否触发
- [ ] 主升模式：竞价不弱则按计划低吸
- [ ] 轮动模式：竞价最强但次日不追，只做回踩低吸

**盘中**
- [ ] 按计划执行买点，同时挂好止损
- [ ] 监控主线涨停家数（锐减=共振破位信号）
- [ ] 沸点/连沸日（规律三）：不追高，等第3日
