## 〇、市场状态判读器（顶层模式层）

> 新增于 2026-08-14。作用：先判定市场处于"主升"还是"轮动"，再决定用哪套执行打法。
> 与三锚表决的关系：三锚定"仓位上限"，判读器定"打法"。两者并行，不冲突。
> v1.5(08-15)：新增第⑤源"涨停端同步性闸门"（全年回测零误判）；切换信号改为"涨停端衰减≥30%或掉下第一"（比新高池敏感）。详见操作手册。

### 盘后5分钟五源打分

| 判读源 | 主升模式信号 | 轮动模式信号 |
|--------|-------------|-------------|
| ① s1题材连续登顶天数 | ≥5天 | ≤2天就换帅 |
| ② 单题材百日新高占比 | 双口径并列：一级行业≥25% 或 最大细分≥20% | 分散 <15%，谁都不突出 |
| ③ 大市值龙头量产新高 | 有（≥300亿龙头创百日新高） | 无，全小票 |
| ④ 高度板 | 打开 >3板 | 卡死 ≤3板 |
| ⑤ 涨停端同步性闸门 | 涨停端第一主类与新高池 s1 同步（同义归一） | 涨停端前3 不含 s1 → 假主升否决 |

**判定规则**：五源全过 → 主升模式；任一不过 → 轮动模式（⑤无同步直接判轮动）。

### 主升模式执行（三层次买入）

| 层次 | 定义 | 买入方式 | 仓位 |
|------|------|---------|------|
| 中军层 | 主线内市值Top龙头，有机构新高确认 | 回踩5日均线/分歧日低吸，拿3-5周波段 | 3成 |
| 分支层 | 主线内未加速细分，有切换信号 | 竞价不弱+回踩均价，半程仓 | 2成 |
| 弹性层 | 高度龙/新高度候选 | 打板纪律，纯交易仓 | 1成 |

**分支启动前置信号**（出现2个才配仓）：子分支首板出现 / 分支龙进百日新高 / 竞价量比靠前。

### 轮动模式执行（四条铁律）

1. 放弃认证主线，总仓压到 2-3成，单题材 ≤1成
2. 竞价跟当日最强、次日不接力（当天参与，次日不追）
3. 只做首板/低位，不做连板（高度板≥4家+连板高度≥5板 才有连板生态）
4. 情绪开关当闸门：昨日涨停今表现 <0 收手；断板率 >60% 空仓

### 模式切换触发条件（靠数据切，不靠感觉切）

- **主升 → 轮动**（涨停端衰减，满足任一即切）：主升日 s1 在涨停端家数 次日衰减≥30%，或 掉下涨停端第一主类。补充确认：共振破位（主线涨停锐减个位数 + 龙头破5日线）在涨停端数据缺失时兜底。
- **轮动 → 主升**：五源共振全过（以判读器当日打分为准）
- 状态切换需连续2个交易日满足新状态才正式切换（与三锚表决同规则）

## 一、大盘定仓位（三锚表决制）

每日计算三个锚点，表决结果决定当日仓位上限。

### 锚1：趋势锚
| 指标 | 上涨信号 | 下跌信号 |
|------|---------|---------|
| 上证收盘 vs MA20 | 收盘 > MA20 | 收盘 < MA20 |
| MA20方向 | 连续3日走高 | 连续3日走低 |

### 锚2：广度锚
全市场收盘价站上MA20的个股比例。
- 比例 > 50% → 上涨
- 比例 < 30% → 下跌

### 锚3：情绪锚
百日新高家数 − 百日新低家数。
- 差值 > 0 → 上涨
- 差值连续3日为负 → 强制空仓
- **禁止用涨停家数−跌停家数作代理**

### 表决结果

| ≥2锚指涨 | ≥2锚指跌 | 其余 |
|----------|----------|------|
| 🟢 上涨市 70-100%仓位 5-8只 | 🔴 下跌市 0-10%仓位 0-1只 | 🟡 震荡市 30-50%仓位 3-5只 |

状态切换需连续2个交易日满足新状态才正式切换。

## 二、板块生命周期分析

### 核心板块（8个）
芯片 / 医药 / 机器人 / 算力 / 通信 / 商业航天 / AI应用 / 物理AI

### 锚点日检测
- **游资型**: 启动日涨停≥15家 + 5日内出现过单日骤降50%以上
- **趋势型**: 启动日涨停<15家 + 5日内温和放大或持平
- **兜底**: 趋势型
- 数据窗口不足时标注"⚠ 锚点待确认"，状态持久化累积

### 阶段标签
| 类型 | 初期 | 中期 | 末期 |
|------|------|------|------|
| 游资型 | <8天 | 8-15天 | >15天 |
| 趋势型 | <20天 | 20-40天 | >40天 |

### 标签校准（仅锚点确认后生效）
- "初期"但回落>70% → 自动升级为"中期"
- "中期"但回落>90%且峰值≥10 → 自动升级为"末期"

### 策略映射
| 生命周期 | 策略 |
|----------|------|
| 萌芽期/初期 | 🟢 优先参与 |
| 中期 | 🟡 选择性参与 |

## 五、百日新高筛选系统（五步法）

### 第一步：海选
| 条件 | 参数 |
|------|------|
| 流通市值 | 20亿 ~ 500亿 |
| ST | 非ST |
| 当日涨幅 | ≥ 5% |
| 量比 | ≥ 1.5 |
| 近20日涨幅 | < 30% |
| MA60 | 收盘站上，方向走平或向上 |
| MA60距离 | 0% ~ 20% |
| 百日新高 | 收盘价创过去100日新高 |

API: `wudao_stock_screener` — 一次传入所有条件

### 第二步：三通道分类
- **通道一（游资点火型）**: 涨停 + 换手<5%
- **通道二（机构建仓型）**: 涨幅5-10% + 换手8-15%
- **通道三（老庄对倒型）**: 振幅>12% + 涨幅<5%

### 第三步：产业链五维验证（通道二专用）
① 核心概念板块 ② 产业链环节 ③ 龙头/核心供应商 ④ 净利润同比增长 ⑤ 机构/北向持股

得分 ≥ 4/5 → 精选狙击池

### 第四步：买点信号
| 买点 | 适用 | 条件 | 仓位 | 止损 |
|------|------|------|------|------|
| A(标准回踩) | 通道二机构票 | 缩量回踩MA5/10/20 + 止跌K线 | 10-15% | 买入日最低价或MA20取低 |
| B(分歧转一致) | 通道一游资票 | 分歧日次日缩量收阳/十字星 | 5-10% | 买入日最低价-3% |

## 六、四条路径选股

### 路径一：机游共振 ⭐/★（第一优先级）
- **选股**: 流通>100亿 + 日均成交>3亿 + 价格>MA60向上
- **P1启动分歧**: 近3日涨停+分歧日(振幅≥4%, 成交≥5日均1.5x, 收MA5上)+次日缩量<分歧60%收阳 → 次日开盘买
- **P2回踩MA13**: 首次缩量回踩MA13(±2%), 量<突破日50%, 止跌K线 → 次日开盘买
- **仓位**: 15-20% | **止损**: 最低价-3%或MA13取低
- **止盈**: 浮盈>10%止损上移成本价; >20%止盈线=MA13

### 路径二：轮动低吸（第二优先级）
- **选股**: 板块RPS(20)近10日曾≥85 + 回调5-15% + 触及MA20(±2%) + 成交<5日均80%
- **买点**: 止跌K线 → 次日开盘买
- **仓位**: 10-15% | **止损**: 收盘跌破MA30离场

### 路径三：纯趋势 💎（第三优先级）
- **选股**: 流通>100亿 + 净利增长>20% + 机构/北向 + MA60向上
- **A2回踩MA20**: 首次缩量回踩MA20, 量<5日均80%, 止跌K线 → 次日开盘买
- **仓位**: 10-15% | **止损**: 收盘跌破MA30离场

### 路径四：纯情绪 🔥（第四优先级）
- **选股**: 板块内成交额前5 + 情绪龙头
- **P1分歧**: 分歧日后次日极缩(<分歧50%)收阳 → 次日开盘买
- **仓位**: 5-10% | **止损**: 最低价-3%或MA13取低, 无条件离场

## 七、执行纪律（三条铁律）

### 铁律一：最大持仓限制
信号超上限时按优先级录取：机游共振 > 轮动低吸 > 纯趋势 > 纯情绪。同优先级按信号出现时间先后。

### 铁律二：止损释放，当日冻结
止损/止盈释放的资金，当日不得重新买入，须等下一交易日。

### 铁律三：被动降仓按风险倒序
卖出顺序：纯情绪 → 纯趋势 → 轮动低吸 → 机游共振。同等优先级内，优先卖出盈利最少或离止损线最近的那只。
