# 板块生命周期分析模块

## 核心板块列表
芯片, 医药, 机器人, 算力, 通信, 商业航天, AI应用, 物理AI

## 锚点日判断
- 游资型: 启动日涨停≥15家 + 5日内出现过单日骤降50%以上
- 趋势型: 启动日涨停<15家 + 5日内温和放大或持平
- 兜底: 趋势型

## 生命周期标签
- 游资型: 初期<8天, 中期8-15天, 末期>15天
- 趋势型: 初期<20天, 中期20-40天, 末期>40天

## 标签校准
- "初期"但回落>70% → "中期"
- "中期"但回落>90% + 峰值≥10 → "末期"
- 仅锚点已确认的板块执行校准

## 数据窗口检测
- 首个数据日涨停≥10 → 标注"⚠ 锚点待确认"
- 数据<5天且非零<3天 → 标注"⚠ 锚点待确认"
- 状态持久化到 state.json，每日累积
